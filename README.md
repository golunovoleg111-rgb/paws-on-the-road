# Лапы в путь

Браузерный пиксельный платформер: Мисти, Гектор и Коди путешествуют через 7 миров и 35 уровней. Первые пять знакомят с управлением, прыжками, рычагами, ящиками и секретами. На 35-м уровне ждёт Богданус.

Откройте index.html в современном браузере. Установка и сервер не нужны. Для общего доступа загрузите файлы в публичный репозиторий и включите Settings → Pages → Deploy from a branch → main / root.

A/D или стрелки — движение; пробел — прыжок и второй прыжок; E — рычаги и толкание ящиков; X — навык героя; Esc — пауза. Есть экранные кнопки для сенсорного экрана.

Прогресс и найденные наряды сохраняются локально в браузере. Наряды выбираются в главном меню. Все уровни доступны после последовательного прохождения. Звук включается отдельной кнопкой. Интернет требуется только для необязательного шрифта, игра использует системный шрифт при его отсутствии.

Это первая играбельная версия. 35 детерминированных уровней используют общую систему платформ и головоломок с нарастанием длины, опасностей и количества механизмов. Полное ручное прохождение всех уровней всеми героями пока не выполнено.
