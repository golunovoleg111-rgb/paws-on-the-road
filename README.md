# Лапы в путь — Рыцари Рассвета

[Играть в браузере](https://golunovoleg111-rgb.github.io/paws-on-the-road/)

Три маленьких рыцаря отправляются за Колоколом Рассвета, который унёс одинокий страж Богданус. 35 уровней в семи мирах, первые пять — обучающие.

## Герои и бой

- **Мисти** — чёрная кошечка в лунных доспехах. Быстро бегает, высоко прыгает; лунная волна на X поражает врагов и подбрасывает Мисти с земли.
- **Гектор** — мейн-кун в тяжёлой броне. Булава наносит двойной урон; X ударяет по области и даёт двухсекундный щит. Быстрее толкает ящики.
- **Коди** — рыжий дуэлянт. Сабля, дальний второй прыжок и боевой рывок на X с краткой неуязвимостью.

На пути встречаются патрулирующие мыши-разбойники, летучие враги и бронированные стражи. Можно атаковать оружием, способностью или прыгать врагам на голову. Богданус уязвим только после своего рывка, когда устал: в это окно работают и прыжок, и оружие.

## Управление

| Клавиша | Действие |
| --- | --- |
| A/D, стрелки | Движение |
| Пробел, W, ↑ | Прыжок; повторное нажатие — второй прыжок |
| J | Атака оружием |
| X | Способность героя; время восстановления видно сверху |
| E | Рычаг, разговор с совой Ори; удерживать для толкания ящика |
| Esc | Пауза |
| Пробел, Enter, E в диалоге | Показать всю реплику / следующая реплика |

Для сенсорных экранов есть кнопки. Звук включается отдельно. Кнопка «Эффекты» уменьшает вспышки, частицы и тряску экрана.

## Сюжет и наряды

Вступление показывает начало истории. В главном меню его можно посмотреть повторно. После каждого уровня есть короткая сюжетная сцена, на границах миров — дополнительные реплики, перед Богданусом — разговор и после победы — эпилог. Любую сцену можно пропустить. Во время диалогов мир стоит на паузе.

Звёзды открывают секретные наряды в гардеробе. Прогресс и косметика из первой версии сохраняются: используется тот же ключ браузерного сохранения. Сохранения локальные, привязаны к браузеру и адресу игры; между устройствами не синхронизируются.

## Запуск и проверка

Откройте `index.html` в современном браузере или используйте GitHub Pages. Сервер, сборка и установка пакетов не нужны. Интернет нужен только для необязательного шрифта.

Автоматические проверки (Node.js):

```sh
node tests/game.test.cjs
```

Проверяются старт и прыжки всех трёх героев на 35 уровнях, механизмы, оружие и способности, урон, сюжетные переходы, сохранения и бой с боссом. Это не заменяет полного ручного прохождения: уровни по-прежнему используют общие шаблоны и требуют дальнейшей балансировки.

## Версия 2.0

Оригинальные пиксельные котики-рыцари с анимацией ходьбы, дыхания, плащей и ударов. Эффекты клинков, лунные снаряды, щит, частицы, вспышки попаданий и лёгкая тряска камеры. Число частиц ограничено; симуляция использует фиксированный шаг, а мир останавливается в меню, паузе и сценах.

## Версия 3.0 — Новые тропы

Все 35 схем уровней заданы отдельно в `levels.js`. Общий генератор одинаковых участков удалён. Теперь есть сад с развилкой, подъём вокруг дерева, колесо мельницы, крыши и чердаки, винтовая башня, архипелаг, маяк, горные перевалы и многоуровневые дворы замка.

- Высокие карты до 1500 пикселей используют вертикальную камеру. Мини-карта показывает платформы, ключ, выход и положение героя.
- Ворота связаны с конкретными рычагами и кнопками. На уровне «Три печати» каждая секция открывается отдельно.
- На уровне «Восемь секунд» дверь закрывается по таймеру; рычаг можно включить повторно.
- Подъёмники перевозят героя по вертикали. Лёд скользит, треснувшие плиты исчезают через 0,9 секунды под лапами и возвращаются через 2,8 секунды.
- Флажки сохраняют точку возврата в текущей попытке. У нижних привалов предусмотрены пути обратно на маршрут.
- 10 исходных материалов — настоящие PNG **128×128** в `assets/textures/`. Земля, корни, черепица, песчаник, снег, руины, замковая кладка, дерево, металл и кора. Загруженные узоры кэшируются, размер игрового окна и персонажей не растягивается.
- Размещение врагов задано для конкретных площадок каждого уровня.

Проверка маршрутов:

```sh
node tests/game.test.cjs
node tests/routes.test.cjs
```

Вторая проверка строит граф прыжков для всех трёх героев и проверяет доступность выходов, ключей, рычагов и секретов, а также путь к выходу от каждой точки возврата. Ограничения: ворота при расчёте открыты, движущиеся платформы рассматриваются в исходной позиции, бой и тайминги льда не моделируются этим графом. Работу таймеров, связей ворот, льда и подъёмников проверяет отдельный набор проверок механик. Полного ручного прохождения всех уровней это не заменяет.

Пересоздать оригинальные текстуры без внешних библиотек: `node scripts/generate-textures.cjs`.
